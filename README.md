# Arduino-Simple-Distance-Tracker
A simple distance tracker with Arduino

---

# Tools:
1. Any Arduino micro-controler.
2. **3** females jumper cables.
3. HC-SR04 Ultrasonic Sensor.

---

# Implementation:

1. Pin sensor GND and VCC pin to Arduino GND and VCC pin.
2. Pin Trigg sensor pin to Digital 3 Arduino Pin.
3. Pin Echo sensor pin to Digital 2 Arduino Pin.
4. Upload the code.
5. Open monitor and the distance should be in the monitor every 0,5 sec.
